# Kala Kothi Wedding Lawns - Commercial Website

A fully responsive, custom-built commercial website developed for *Kala Kothi Wedding Lawns* to serve as their primary digital storefront and client inquiry portal. 

🌐 **Live Site:** [kalakothiweddinglawns.com](https://kalakothiweddinglawns.com)

## Project Overview
This project involved the end-to-end development of a modern landing page designed to showcase the venue's amenities, host embedded media, and drive customer conversions. 

### Key Features
* **Mobile-First Responsive Design:** Engineered custom CSS layout fixes to ensure fluid scaling and optimal viewing across desktop, tablet, and mobile devices.
* **Rich Media Integration:** Optimized and embedded high-quality venue images and video tours without sacrificing page load speeds.
* **Production Deployment:** Configured production hosting via Netlify and managed DNS routing to point the GoDaddy custom domain to Netlify's nameservers.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Hosting & Deployment:** Netlify
* **DNS Management:** GoDaddy
